# Particle textures

From the **Kenney Particle Pack** — <https://kenney.nl/assets/particle-pack>

Licence: **CC0 1.0 Universal** (public domain dedication). No attribution is
required; it is recorded here so the provenance of anything shipped inside the
binary stays answerable.

A curated subset of the pack's 96 files. The ones left out are either shapes
`BuiltInTextures` already draws in code (`circle_*`, `light_*`) or near-
duplicates of one that is included (`smoke_01`…`smoke_10`), which would make the
picker unreadable without adding anything to draw with.
